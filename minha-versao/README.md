# minha-versao/

Escreva aqui as **suas** soluções. O `run.sh` procura os arquivos pelo nome, em qualquer subpasta. Sugestão de organização (igual à entrega na 42):

```
minha-versao/
├── shell00/
│   ├── ex00/ola.sh
│   └── ...
├── c00/
│   ├── ex00/ft_putchar.c
│   ├── ex01/ft_print_alphabet.c
│   └── ...
├── c01/ ...
└── exames/ ...
```

Depois:

```bash
./run.sh ft_putchar
```

Não coloque `main` nos seus arquivos: o `main.c` de teste fica em `testes/`.
